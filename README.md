# GLOBAL SUPERSTORE DASHBOARD
Global superstore sales Analytics Using Excel, SQL, Power BI and DAX
Project Overview

This project analyzes Global Superstore sales data to identify sales trends, profitability, customer behavior, product performance, and regional performance. The analysis was performed using Excel, SQL, Power BI, and DAX to generate meaningful business insights through an interactive dashboard.

Dataset Overview

The dataset contains transactional sales data including information about orders, customers, products, sales, profit, quantity, discounts, categories, sub-categories, regions, countries, and shipping details.

Key Columns

* Order ID
* Order Date
* Ship Date
* Customer Name
* Segment
* Country
* City
* State
* Region
* Category
* Sub-Category
* Product Name
* Sales
* Quantity
* Discount
* Profit

Tools & Technologies

 Excel – Data cleaning and exploratory analysis
 SQL – Data analysis and business queries
 Power BI – Interactive dashboard and visualization
 DAX – Calculated measures and KPIs

Key Insights

* Identified top-performing categories and sub-categories.
* Analyzed regional sales and profitability.
* Identified products contributing significantly to overall sales.
* Evaluated the impact of discounts on profitability.
* Analyzed sales trends over time.

Project Outcome

The project provides a data-driven view of business performance and helps identify areas of growth, profitability, and improvement through interactive Power BI visualizations.
